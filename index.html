1Once only

Set up Tampermonkey

Tampermonkey is the Chrome extension that runs the scripts. Do these three steps once and you're set for good.

1

Add it to Chrome

Open the Chrome Web Store, click Add to Chrome, then Add extension.

Get Tampermonkey
2

Pin it

Click the puzzle piece in Chrome's toolbar, then the pin next to Tampermonkey.

Don't skip this
3

Allow user scripts

Go to chrome://extensions, click Details on Tampermonkey and turn on Allow User Scripts. Not there? Turn on Developer mode (top right) instead.

2Pick and choose

Install the scripts you want

Install one, or all four. They work together, and each one can be switched off from the Tampermonkey icon.

Click Install, click Install again on Tampermonkey's screen, then refresh HubSpot.

Company filters

Sensible lists when you add contacts or companies.

  • Add existing Contact only lists people at that customer's companies and head office. Show all is one click away.
  • Add existing Company shows each company's products, owner, contacts and tickets, and hides the stages you don't deal with.
Install How to use

Unlinked contacts

Spot contacts who aren't on the customer's company.

On a Help Desk ticket, an amber chip by the title says how many contacts aren't linked to the ticket's company. Click Link to fix it, with Undo if you pick the wrong one.

Install How to use

Payments badge

Adyen or WPay, at a glance.

A Adyen or WPay badge under the company's name, next to the Help Desk ticket title and on company cards. Hover it for the merchant ID.

Install How to use

Quick actions BETA

Meetings, tasks and travel from any record.

  • Book a meeting with the title and a link back to the record filled in.
  • Create a follow-up task linked to the record.
  • See the drive time from the nearest Oolio office, or plan a trip to several customers.
Install How to use

Good to know

They update themselves

New versions arrive within a day. Tampermonkey > Utilities > Check for userscript updates gets them now.

Easy to switch off

Click the Tampermonkey icon in HubSpot to turn any script off or on.
